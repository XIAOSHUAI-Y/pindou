# 拼豆图纸机

图片一键转拼豆图纸的纯前端工具，全部处理在浏览器本地完成，图片不上传。

**在线使用**：https://xiaoshuai-y.github.io/pindou/

## 功能

- **图片转图纸**：拖拽 / 粘贴 / 选择图片，自动像素化并匹配豆色
- **MARD 221 色板**：内置 MARD 221 色号表（另附通用 39 色），可停用没有的豆色
- **常用豆板预设**：15×15 / 20×20 / 29×29 标准 / 36×36 / 58×58 / 87×87 / 116×116
- **色号高亮**：点某个色号，图纸只显示该色位置，拼豆对照方便
- **逐格编辑**：画笔上色、橡皮擦除、撤销（⌘/Ctrl+Z），修正配错的颜色
- **用量统计**：每个色号需要多少颗，比例条一目了然
- **豆子库存**：记录每个色号库存（1 包 = 1000 颗），自动核算缺口、拼完一键扣减，localStorage 本地保存
- **导入图纸核算**：导入现成图纸图片，自动识别网格尺寸（边缘投影 + 周期重建），格心中位采样避开网格线和符号，同色聚类后匹配色号，算出用量并和库存对比
- **导出**：带坐标和色号的 PNG 图纸（可直接打印）、用量清单 CSV
- 支持移动端触屏操作，深浅色主题

## 本地运行

无需构建，直接用浏览器打开 `index.html` 即可。

## 文件

- `index.html` — 页面与全部逻辑
- `palettes.js` — MARD 221 色号表（社区 Bitbead HEX 版，屏幕近似值，请以实物豆为准）
